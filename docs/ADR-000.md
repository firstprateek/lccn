# ADR-000: Tech Choices

## Context
- Local-first editor MVP; must be fast to iterate, web-component friendly, offline-capable.
- Target: modern browsers, minimal deps, smooth CI from Day 1.

## Decision
- **TypeScript (strict)** for correctness + refactors.
- **LIT** for lightweight web components.
- **Vite** for dev/build speed.
- **Offline**: IndexedDB + Service Worker (V1 stubs).
- **Tests**: Vitest (unit), Playwright (e2e).
- **CI**: GitHub Actions on PR.

## Consequences
- **Pros**: small dependency surface, fast HMR, easy web-comp reuse, offline path clear.
- **Cons**: no framework router; more hand-rolled infra (state mgmt, data sync); DX tradeoffs vs React toolchain.

## Alternatives
- **React/Next**: faster scaffolding & ecosystem; heavier runtime; not needed for web-component centric MVP.
- **PWA libs (Workbox, Dexie)**: great DX, but deferring to keep surface area small in V1.
- **Jest/Cypress**: capable, but Vitest/Playwright are faster & simpler with Vite.
